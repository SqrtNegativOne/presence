# Demo Assets

Two classes are bundled so anyone can try Presence end-to-end without uploading
their own photos. The demo seeder enrols both at startup.

## `synthetic/` — CC0 generated faces
Four AI-generated portraits from `thispersondoesnotexist.com`. None of these
are real people. Class name: **Demo-Class**.

- `synthetic/students/{alice,bob,carol,dave}.jpg`
- `synthetic/group.jpg`  (2×2 composite of the four)

## `apollo11/` — real-life public-domain photos
The Apollo 11 prime crew. All photographs are works of NASA in the public
domain. Class name: **Apollo-11**.

- `apollo11/students/armstrong.jpg`  — Neil Armstrong (NASA portrait)
- `apollo11/students/aldrin.jpg`     — Buzz Aldrin (NASA portrait)
- `apollo11/students/collins.jpg`    — Michael Collins (NASA portrait)
- `apollo11/group.jpg`               — NASA file `GPN-2000-001164`, the
                                       official Apollo 11 prime crew portrait

Source: Wikimedia Commons. All photos are NASA works in the public domain.
