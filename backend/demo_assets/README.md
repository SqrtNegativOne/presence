# Demo Assets

None of these are real people. Used to seed the built-in demo user so anyone
can try Presence end-to-end without uploading their own photos.

- `students/{alice,bob,carol,dave}.jpg` — 512×512 solo portraits
- `group/class.jpg`                     — 2×2 composite group photo of the four
